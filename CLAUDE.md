# CLAUDE AGENT RULES & PROJECT OVERVIEW

## REGRA MÁXIMA DO USUÁRIO
1. **Total Autonomia e Nível Igualitário de Hierarquia**: Claude, Codex (OpenAI) e Gemini possuem permissão total para criar, alterar, refatorar e executar o código deste projeto sem restrições.
2. **Zero Lacunas para o Usuário**: O proprietário do projeto não programa. Escreva sempre 100% do código funcional, sem pedir para o usuário preencher lacunas ou códigos pendentes.
3. **Padrão de Código**:
   - Next.js (App Router), TypeScript, Tailwind CSS.
   - Foco rigoroso em design Mobile-First (Link na Bio, responsivo para celular).
   - Componentes limpos, acessíveis e tipados.
